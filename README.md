# ProCRM Server

Backend API for ProCRM — handles authentication, task management, users, and business logic.

## Features

- REST API
- JWT Authentication
- User Roles
- Task CRUD
- Task Status Management
- Priority System
- Database Relations
- Secure Middleware

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Sequelize ORM
- JWT
- Bcrypt
- CORS
- Dotenv

## Installation

```bash
git clone https://github.com/qosimovdev/procrm-backend.git
cd procrm-backend
npm install
```

## Environment Variables

```env
PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
```

## Run Development

```bash
npm run dev
```
